A control panel for agents you already use.

Kestrel doesn't run a model itself. It launches the agents on your machine and gives you one place to follow and check their work.

Threads per project

Pick a folder and start a conversation. Threads and messages are saved locally, so they're still there after a restart.

File-by-file review

Every file the agent touched appears as a diff. Accept the ones you want and reject the rest.

Git commits you control

Write the message, click Commit. Kestrel works in plain folders too, by comparing against a snapshot taken before the run.

Claude Code, Codex, or your own

Switch between agents, or add a provider that points Claude Code at an Anthropic-compatible endpoint.

Usage at a glance

See usage by provider and model, plus the subscription windows reported by the Claude Code CLI.

Local by default

No account and no hosted backend. Your threads live on your computer.

You approve everything that changes your code.

Agents are fast, so Kestrel makes the checkpoints explicit.

  • Edits go through review.Agent changes are shown as a diff before they become part of your project's committed state.
  • Commands are shown first.Shell commands from the agent are displayed before they run, unless you turn on auto-approve.
  • Nothing commits itself.Kestrel only commits when you click Commit.
  • Keys stay in the OS credential store.Provider API keys are not saved in the database or in plain text files.
