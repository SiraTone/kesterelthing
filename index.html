A window for every agent.

Most agent tools give you one chat at a time. In Kestrel each thread opens as its own window on a shared canvas, so a slow task doesn't block the next one.

  • Move, resize, snap.Drag a window to a screen edge to snap it to half the canvas, or tile everything in one click.
  • Minimize to the dock.A minimized window keeps working, and its dock button pulses until it's done.
  • Your layout is remembered.Each project reopens with its windows where you left them.
  • One tab per project.Switch projects from the tab bar at the top without losing track of what's running.

Review is part of the workspace.

The changes panel sits beside your windows. Every file an agent touched is a diff you can accept or reject, and nothing is committed until you say so. Try it on the left.

  • Works with Git or plain folders.For folders without Git, Kestrel compares against a snapshot taken before the run.
  • Commands are shown first.Shell commands from an agent are displayed before they run, unless you turn on auto-approve.
  • Nothing commits itself.Kestrel only commits when you click Commit.

Bring the agents you already use.

Kestrel doesn't run a model itself. It launches the agents on your machine, so your existing logins, plans and settings carry over.

A different agent per window

Each window keeps its own agent and model, so one project can use several at once.

Custom providers

Point Claude Code at any Anthropic-compatible endpoint. API keys are stored in the OS credential store, not in a file.
